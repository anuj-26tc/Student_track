Student Skill Development and Academic Progress Tracking Platform

Modules:
1. Login and Sign Up
2. Dashboard
3. Skills
4. Marks

Tools: HTML, CSS, Python (Flask), SQLite, Git/GitHub

How to run:
1. Install Python (tick "Add Python to PATH")
2. Open cmd and type: pip install flask
3. Go inside the project folder
4. Type: python app.py
5. Open http://127.0.0.1:5000 in Chrome
